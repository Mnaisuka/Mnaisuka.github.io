从准备到启程

按顺序完成环境配置，再把模组放入游戏目录。安装前请先备份存档。

重要说明

当前 Mod 仅支持 Steam 版游戏和 Windows 系统。本网站与 Hinterland Games 无关联，只提供 Mod 信息与下载入口。

01—04

安装步骤

首次安装时依序操作

  1. 01

    关闭崩溃报告与数据分析

    如果你尚未关闭这些选项，请先启动游戏并关闭它们。除非确认是官方问题，否则请勿打扰开发者。

  2. 02

    备份游戏存档

    Mod 通常经过测试，但仍可能导致问题。安装前备份存档：

    C:\Users\[用户名]\AppData\Local\Hinterland\TheLongDark
  3. 03

    准备运行环境

    确保已安装以下依赖：

    • Microsoft Visual C++ 2015–2019 运行库（64 位）
    • .NET 6.0 Runtime
  4. 04

    安装 MelonLoader

    • 下载并运行 MelonLoader.Installer.exe。
    • 选择 The Long Dark（或手动添加游戏路径）。
    • 选择版本 0.7.2；如需 Nightly 版本，勾选 Enable Nightly Builds 并选择最新版本。
    • 等待安装完成。
  5. 05

    安装模组并检查前置项

    如下载的是 ZIP，请先解压。将 .dll 或 .modcomponent 文件放入游戏目录的 Mods 文件夹，并按模组说明选择正确版本。安装所有前置模组后再启动游戏。

  6. 06

    启动游戏

    启动游戏并确认模组正常加载，祝你在荒野中旅途顺利。

FAQ

常见问题

遇到问题时先检查这些项目

出现 “iL2CPP-init detour failed” 错误

请确认已安装 .NET 6 Runtime。

提示缺少 UnhollowerBaseLib

该模组可能未适配当前游戏版本，请检查模组页面的兼容信息；若仍无法使用，请暂时移除该模组。

游戏启动时崩溃

确认 MelonLoader 版本为 0.7.2，并检查是否已安装所有前置模组。

Epic 版本能否使用模组？

Epic 版本目前不受支持。

如何卸载 MelonLoader？

重新运行安装程序并选择游戏即可卸载；也可以在确认已备份后，手动删除 MelonLoader、Mods、Plugins、UserData、UserLibs 文件夹和 version.dll。

模组支持剧情模式吗？

目前不支持。生存模式与剧情模式已分离，分别安装也可能遇到加载问题。
